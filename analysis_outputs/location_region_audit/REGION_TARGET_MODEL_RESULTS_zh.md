# VR-TriRef 非物体／区域目标分组结果

## 结论

按当前显式 taxonomy 和现有 4,000 条 GT 交互分组后，GPT-6.1-Sol 在 **Exp2 声明坐标空间重映射**下，对仅非物体组和混合组的 2D 点定位分数高于现有开源模型。Exp1 的纯非物体组由 Qwen3-VL-30B 略高；Exp3 各模型在纯非物体组接近，Exact 均为 0。纯非物体组只有 109 条，且包含建筑等边界语义存在争议的条目，应把结果视为当前 taxonomy 下的诊断。

分组来自先前生成的 `region_interactions.csv`：仅物体 2,628 条、仅非物体 109 条、混合 1,263 条，合计 4,000 条。混合样本单列，没有并入纯非物体组。无待确认 GT 引用。

## Exp1：Anchor Selection

单元格为 Micro-F1 / Exact，均以该组交互数为分母；Micro-F1 按 referent TP/FP/FN 汇总。

| 模型 | 仅物体（n=2,628） | 仅非物体（n=109） | 混合（n=1,263） |
|---|---:|---:|---:|
| Qwen3-VL-30B-A3B | 0.5692 / 0.4030 | 0.5530 / 0.5321 | 0.4896 / 0.1568 |
| Qwen3-VL-8B | 0.5347 / 0.3265 | 0.3761 / 0.3578 | 0.3556 / 0.0428 |
| InternVL3-38B | 0.5436 / 0.3478 | 0.3470 / 0.3303 | 0.3999 / 0.0689 |
| gpt-6.1-sol | 0.6786 / 0.5019 | 0.5446 / 0.5138 | 0.5791 / 0.2146 |

纯非物体组中 Qwen3-VL-30B 的 Micro-F1 / Exact 为 **0.5530 / 0.5321**，GPT-6.1-Sol 为 **0.5446 / 0.5138**；GPT 略低。混合组 GPT 为 **0.5791 / 0.2146**，高于 Qwen3-VL-30B 的 0.4896 / 0.1568。

## Exp2：Projected-2D

单元格为 Temporal-F1 / Point-F1@100 / Joint-F1@100。GPT-6.1-Sol 采用按模型声明坐标空间重映射后的已有评测明细；没有使用其原始坐标映射结果。Qwen 和 InternVL 数值来自其已冻结的 benchmark 评测汇总。

| 模型 | 仅物体（n=2,628） | 仅非物体（n=109） | 混合（n=1,263） |
|---|---:|---:|---:|
| Qwen3-VL-30B-A3B | 0.7234 / 0.2910 / 0.2397 | 0.5182 / 0.0636 / 0.0545 | 0.7597 / 0.1913 / 0.1602 |
| Qwen3-VL-8B | 0.7358 / 0.2661 / 0.2282 | 0.5364 / 0.0636 / 0.0455 | 0.7695 / 0.1917 / 0.1640 |
| InternVL3-38B | 0.7303 / 0.1283 / 0.1030 | 0.6182 / 0.1091 / 0.0727 | 0.7410 / 0.1146 / 0.0902 |
| gpt-6.1-sol | 0.7559 / 0.4007 / 0.3494 | 0.6239 / 0.3028 / 0.2294 | 0.7821 / 0.3060 / 0.2694 |

GPT-6.1-Sol 在纯非物体组的 Point-F1@100 / Joint-F1@100 为 **0.3028 / 0.2294**；最强开源对应值分别是 InternVL3-38B 的 0.1091 / 0.0727。混合组 GPT 为 **0.3060 / 0.2694**，开源最好分别为 Qwen3-VL-8B 的 0.1917 / 0.1640。GPT 的时间选择也略高。

**Exp2 可比性说明：** GPT 采用模型声明坐标空间的 sensitivity 重映射；Qwen/InternVL 采用冻结评测产物。结果回答“按目标组观察现有分数如何”，但由于坐标适配口径并非完全相同，不宜把差值表述成严格控制坐标处理后的模型因果优势。

单元格为 Anchor-F1 / Exact / Margin-F1@1 / SNE；SNE 越低越好。SNE 按评测保存的逐匹配误差逐点汇总。

在纯非物体组，Anchor-F1 为 0.4198–0.4566，GPT 为 **0.4268**；GPT 与两种 Qwen 的 Exact 都是 **0**（InternVL3-38B 为 0.0183），Margin-F1@1 也接近（GPT 0.3130，Qwen3-VL-8B 0.3155，Qwen3-VL-30B 0.3091）。该组没有显示 GPT 带来明确的 3D 提升。混合组 GPT Anchor-F1 为 **0.4596**，略高于 Qwen3-VL-30B 的 0.4569。

## 解读边界

- 这里的“非物体”完全沿用已有 37-anchor taxonomy，没有按名称或指令重新分类，也没有改动原有 GT / 评分。场景交互空间及模型预测结果都通过 `scene::row_index` 对齐。
- 当前纯非物体 109 条中，**85 条来自 scene1 的 building anchors**；这 85 条指令都提到 building，其中 43 条还提到 door、24 条 entrance、18 条 window。另有 scene3 的 building 目标 21 条，以及 scene4_room3 的 room 目标 3 条。因此部分纯非物体组在自然语言层面也可能是在指大型建筑或其局部，类别语义需要谨慎解释。示例 ID：`scene1::4`（“Touch the entrance of the main building.” → `building7`）、`scene3::4`（“assess that building.” → `building1`）、`scene4_room3::19`（“Inspect the area in front of room1.” → `room1`）。
- Exp3 是 measured point-hypothesis 协议，报告的是现有 nearest-anchor / margin 评分结果，不代表区域边界定位；GPT-6.1-Sol 与两种 Qwen 在该组的 exact set 命中为 0；InternVL3-38B 为 0.0183。
- 三个 setting 的有效输出率有差异；CSV 同时保留每类 `n` 和 `valid`。分组指标按 4,000 条固定 GT 类别统计，沿用原评测将无效结果作为空预测的规则。
